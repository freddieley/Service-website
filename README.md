# Bluo — Web Design & Development

Production website for Bluo, Freddie Ley's independent web design and development service.

## Stack

- Next.js App Router
- React
- TypeScript
- Custom CSS
- Vercel-ready

## Positioning

**£199 Launch package**

Modern, mobile-first websites for local businesses. The service is deliberately email-first: enquiries are scoped in writing and the final project is agreed before payment.

## Before launch

- Confirm the public domain and connect it to the Vercel project.
- Replace the GitHub portfolio link with the public portfolio URL once the portfolio frontend is deployed.
- Add final Terms, Privacy and any required cookie/analytics notices.
- Set up the preferred payment flow (Stripe and/or bank transfer).
- Set up a professional business email when ready; the current contact email is deliberately the supplied iCloud address.
- Test the enquiry mailto flow on iOS, macOS, Windows and Android.
- Add real commissioned work to the portfolio as it becomes available.

## Product principles

- Motion is used as accent, feedback and atmosphere — not as constant decoration.
- The service is email-first; there is intentionally no forced call-booking flow.
- The £199 package has a deliberately narrow scope.
- Larger projects are scoped separately rather than hidden behind a generic pricing table.
